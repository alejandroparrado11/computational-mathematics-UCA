# Computational Mathematics & Algorithmic Problem Solving

This repository contains a collection of academic and personal projects developed during my B.S. in Mathematics at Universidad de Cádiz. The focus of these projects is to solve complex mathematical problems using efficient algorithms, optimized memory management, and rigorous computational logic.

## 🛠️ Tech Stack & Skills
* **Languages:** C, Python, R
* **Core Concepts:** Numerical Analysis, Linear Algebra, Optimization, Statistical Modeling, Algorithm Complexity

## 📂 Main Projects

### 1. Numerical Analysis & Matrix Optimization (C)
* Designed and implemented efficient algorithms in C to solve systems of linear equations and matrix operations.
* Optimized execution time and memory allocation, analyzing big-O computational complexity.

### 2. Statistical Data Modeling (R / Python)
* Developed scripts to process data, run statistical tests, and visualize mathematical distributions.
* Applied probability models to simulate random variables and stochastic scenarios.

  
### 3. Fuzzy Logic Inference Engine & Climate Controller (Python)
* Solved a complex continuous system control problem using custom triangular and trapezoidal mathematical functions from scratch.
* Implemented Mamdani Max-Min composition matrices and solved numerical integration via Centroid Defuzzification vectors using NumPy.
* Managed visualization plots using Matplotlib to map out linguistic membership variable intervals.
